# Social Media Command Center — Facebook, Threads, YouTube & GitHub Syndication

Enterprise $100\text{vw} \times 100\text{vh}$ command console for presenting **Chase R. Hamilton's** **27 Open-Source GitHub Repositories (`@Chammin00`)** and **YouTube Studio Ecosystem (`ApexPulse 3D Gallery` & `@CartoonWhiteNoise`)** across **Facebook**, **Threads**, **YouTube**, and **LinkedIn**.

## Key Features
- **Meta Outbound-Link Penalty Bypass**: Pre-configured 3-part Threads chain (Post 1 zero-link hook, Post 2 technical architecture, Post 3 link stack) and Facebook Main Post + Pinned First Comment workflow.
- **One-Click Copy & Character Verification**: Live character counters calibrated for Threads Bio (`150 chars`), Threads Posts (`500 chars`), and Facebook Intro Bio (`101 chars`).
- **27-Repo GitHub MCP Matrix**: Synchronized with `user:Chammin00` via GitHub MCP and `linkedin-mcp` executive strategy.
- **High-Gloss Lacquer & Antigravity MCP Baseline v2.0**: Includes `Ctrl+K` instant filtering, `Ctrl+M` MCP Telemetry HUD, `Ctrl+E` live DOM editor, and Web Speech API audio narration.

## Quick Launch
```powershell
Set-Location "g:\My Drive\Antigravity\Projects\My Social Media"
.\Start-SocialCommandCenter.ps1
```
To launch the Command Center and open Facebook, Threads, GitHub, and your live Portfolio simultaneously:
```powershell
Set-Location "g:\My Drive\Antigravity\Projects\My Social Media"
.\Start-SocialCommandCenter.ps1 -OpenSocialTabs
```
